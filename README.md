## ♠ Chi sono

Benvenuto nel mio backstage digitale.

Sono uno sviluppatore **Full-Stack con una forte passione per il Frontend, la UI/UX e la User Experience**.

L'illusionismo mi ha insegnato che ogni dettaglio conta: il risultato finale deve sembrare semplice, naturale e immediato, anche quando dietro le quinte c'è molta complessità. È lo stesso approccio che porto nello sviluppo.

Mi piace trasformare idee in **interfacce pulite, intuitive e coinvolgenti**, cercando il punto d'incontro tra codice, design e usabilità.

---

## ♥ Cosa faccio

- **Frontend Development** — React, TypeScript e architettura di interfacce
- **UI/UX** — attenzione al design, all'interazione e alla User Experience
- **Mobile Development** — applicazioni con React Native ed Expo
- **Full-Stack Development** — esperienza anche con Node.js, API e database

In questo periodo sto approfondendo React e TypeScript, lo sviluppo mobile con React Native, l'interaction design e l'architettura frontend orientata al codice manutenibile.
